# Sosumi MCP Bundle

This bundle runs a local stdio MCP server with four read-only Apple documentation tools:
`searchAppleDocumentation`, `fetchAppleDocumentation`, `fetchAppleVideoTranscript`, and
`fetchExternalDocumentation`.

It retrieves public Apple Developer content and renders it as Markdown. It is a local fork of
[NSHipster's sosumi.ai](https://github.com/NSHipster/sosumi.ai); Apple owns the retrieved
documentation and media. See `LICENSE.md` for the MIT license and
`server/THIRD_PARTY_NOTICES.md` for bundled dependency notices.
